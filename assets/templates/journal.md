# 决策与成交日志

| 字段 | 记录 |
| --- | --- |
| 案例、截止时间和规则版本 | 尚未揭示哪些数据 |
| 事实／推断／未知 | 分开记录 |
| 决策及理由 | 买入、卖出、持有、等待或放弃 |
| 仓位与风险计算 | 价格、数量、费用、组合假设 |
| 委托与撤单 | 提交时点、类型、价格、数量、状态 |
| 实际成交 | 时点、价格、数量、费用及剩余申报 |
| 账户变化 | 现金、冻结资金、持仓与可卖数量 |
| 管理与退出 | 采用哪条规则及其触发依据 |
| 执行偏差 | 偏离计划的动作与当时原因 |
| 结果 | 净收益、持有时间、浮动风险 |
| 过程评价 | 哪些符合计划，哪些需要改进 |
| 下一步 | 补课、继续观察或一项待验证假设 |

先记录判断再揭示后续。修改时保留原值和修改时间。未交易也是一条决策。
