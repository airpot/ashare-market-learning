# 交易规则卡

名称／版本／制定时间／案例是否合成：

| 字段 | 必须能观察或核对的内容 |
| --- | --- |
| 股票池 | 产品、市场、筛选及排除条件 |
| 适用背景 | 状态判定、数据来源和不适用情形 |
| 等待条件 | 形成机会的事实及观察周期 |
| 行动触发 | 明确指标、价格关系或结构条件 |
| 信号确认 | 使用已收盘或未完成数据、确认时刻 |
| 执行 | 确认后何时申报、采用什么委托、未成交怎么办 |
| 数量 | 损失预算、现金、费用、申报单位与组合限制 |
| 亏损退出 | 触发、可执行动作及跳空或停牌情形 |
| 盈利退出 | 事先定义的持有或退出办法 |
| 时间与逻辑退出 | 等待时限、原先判断失效条件 |
| 加减仓与再入场 | 新决策的条件及重新核算 |
| 不交易与暂停 | 数据不明、条件冲突、风险或行为约束 |
| 验证 | 案例选择、费用、基准、未见样本与修改记录 |

规则完整不等于收益有效。评估结论与其证据范围另外保存。
