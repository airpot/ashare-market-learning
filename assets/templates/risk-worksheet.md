# 风险核算练习表

| 输入 | 值与依据 |
| --- | --- |
| 计划入场价、计划退出价 | 价格及为何采用 |
| 单笔计划损失预算 | 本题假设及单位 |
| 可用现金 | 是否已扣其他冻结资金 |
| 费用预留 | 假设或当前实际收费来源 |
| 申报数量单位 | 本题假设或证券适用规则 |
| 其他持仓及相关暴露 | 同行业、同事件或市场共同影响 |

计算每股计划价差；扣除成本预留后算损失约束数量；再算现金约束数量；取同时满足条件且符合申报单位的数量。若不足一个单位，记录不交易及原因。

| 输出 | 记录 |
| --- | --- |
| 计划数量及现金占用 | 计算过程 |
| 按计划价退出的损失 | 价差与费用分别列出 |
| 跳空与未成交情景 | 假设变更后可能发生什么 |
| 组合风险复核 | 单只和合计暴露 |

这是条件估算，真实损失可能更大。计划退出价格不是成交保证。
