# 概念查询与易混区别

先查需要的概念，再回原课。下列短释用于定位，详细机制、图例、适用条件和理解确认在链接单元。看到短释不代表已掌握。

| 概念 | 入门短释与容易混淆之处 | 详细单元 |
| --- | --- | --- |
| 股票、股价、公司 | 股票代表股份；股价是交易价格；公司经营与交易价格相关但含义不同 | [M01-U01](modules/module-01.md#u01-p01) |
| 价差与分红 | 卖出买入的价差与公司分配是不同现金流，分红还须结合除权和税费看总收益 | [M01-U01](modules/module-01.md#u01-p02) |
| 发行与流通 | 发行募集资金与投资者之间买卖已发行股票是不同环节 | [M01-U03](modules/module-01.md#u03-p01) |
| 交易所与券商 | 交易所组织交易，券商提供账户及经纪等服务，实际责任须看规则与协议 | [M01-U02](modules/module-01.md#u02-p01) |
| 指数与个股 | 指数依编制规则反映一组证券表现，不能代表每只股票都同方向变化 | [M01-U04](modules/module-01.md#u04-p02) |
| 证券账户与资金账户 | 分别记录证券权益与交易资金等，资金转入不代表买入股票 | [M02-U01](modules/module-02.md#u01-p01) |
| 风险意愿与承受能力 | 愿不愿冒险与损失是否影响现实安排需要分别判断 | [M02-U04](modules/module-02.md#u04-p01) |
| 股票与ETF | 一家公司股份与基金份额的对象、风险来源、规则不同 | [M02-U03](modules/module-02.md#u03-p01) |
| 委托与成交 | 提交买卖请求后，只有撮合成交的数量才形成实际交易 | [M03-U03](modules/module-03.md#u03-p01) |
| 限价与市价类申报 | 对成交价格与成交速度的约束不同，可用类型还取决于市场、品种与阶段 | [M03-U01](modules/module-03.md#u01-p02) |
| 集合竞价与连续竞价 | 在不同交易阶段采用不同匹配机制，不等于所有申报时段都可撤单 | [M03-U02](modules/module-03.md#u02-p01) |
| 涨跌幅与实际亏损 | 单日价格限制不是持仓累计损失或保证可卖出的界限 | [M03-U04](modules/module-03.md#u04-p01) |
| 可用、可取与可卖 | 买证券可用的现金、可转出现金及可卖股份是不同状态 | [M04-U01](modules/module-04.md#u01-p01) |
| 净收益与涨跌幅 | 价格涨跌比例与考虑数量、费用及现金流后的交易结果不同 | [M04-U02](modules/module-04.md#u02-p01) |
| 仓位与计划损失 | 投入资金占比与按假设退出价估算的损失是不同维度 | [M04-U03](modules/module-04.md#u03-p01) |
| 分散与相关风险 | 持有多只股票仍可能集中暴露于同一行业或事件 | [M04-U04](modules/module-04.md#u04-p01) |
| 利润与现金流 | 会计盈利和现金实际流入流出并非一回事 | [M05-U01](modules/module-05.md#u01-p01) |
| 公告时点 | 交易中只能使用当时已公开且可获得的信息 | [M05-U02](modules/module-05.md#u02-p01) |
| 除权除息 | 股份或分配改变时的价格参考调整，须与总财富和费用一起理解 | [M05-U03](modules/module-05.md#u03-p01) |
| 观察名单 | 值得继续观察的候选集合，入选尚不是买入行动 | [M05-U04](modules/module-05.md#u04-p01) |
| 市值与股价 | 市值还取决于采用的股份数量口径，低股价不直接等于便宜 | [M06-U01](modules/module-06.md#u01-p01) |
| 成交量与成交额 | 数量与金额是不同单位；一笔成交同时有买卖双方 | [M06-U02](modules/module-06.md#u02-p01) |
| 换手率与量比 | 前者用股份口径衡量交易活跃程度，后者比较当前与参考成交速率，具体平台定义须核对 | [M06-U02](modules/module-06.md#u02-p02) |
| 挂单与成交 | 盘口中的意向申报可以改变，不能当作已完成交易或资金意图证明 | [M06-U03](modules/module-06.md#u03-p01) |
| OHLC | 一段时间的开、高、低、收四价，不包含完整先后路径 | [M07-U01](modules/module-07.md#u01-p01) |
| 阳线与日上涨 | 阳线比较收盘和开盘；普通日涨跌比较收盘与适用参考价 | [M07-U02](modules/module-07.md#u02-p01) |
| 实体与影线 | 实体连接开收，影线延伸至高低，几何关系由四价决定 | [M07-U01](modules/module-07.md#u01-p02) |
| 周期与未完成K线 | 聚合窗口改变信息粒度；未收盘的高低收仍可变化 | [M07-U03](modules/module-07.md#u03-p01) |
| 复权与成交价格 | 复权用于比较序列，历史图上的调整值不一定是当时可成交价格 | [M07-U04](modules/module-07.md#u04-p01) |
| 锤子线与上吊线 | 外形相似，前序走势与位置参与命名和解释 | [M08-U01](modules/module-08.md#u01-p01) |
| 吞没与孕线 | 比较前后实体关系，仍需声明具体口径和背景 | [M08-U02](modules/module-08.md#u02-p01) |
| 反转与持续形态 | 描述候选结构和背景，不能单靠名称确定后续路径 | [M08-U03](modules/module-08.md#u03-p01) |
| 趋势与震荡 | 用一定观察尺度描述高低点和价格结构，尺度变化可改变描述 | [M09-U01](modules/module-09.md#u01-p01) |
| 支撑与压力 | 由已知交易结构等形成的观察区域，不是价格必然反转的屏障 | [M09-U02](modules/module-09.md#u02-p01) |
| 突破与假突破 | 需定义突破阈值、确认方式和失效条件，不能事后随意改名 | [M09-U04](modules/module-09.md#u04-p01) |
| MA与MACD | 由价格变换产生的统计量，参数、初始化与滞后需要解释 | [M10-U02](modules/module-10.md#u02-p01) |
| 背景与触发 | 允许观察机会的环境，与触发具体行动的条件不同 | [M10-U03](modules/module-10.md#u03-p01) |
| 期望与胜率 | 胜率需结合平均盈亏和成本，不能单独判断方法收益 | [M10-U04](modules/module-10.md#u04-p01) |
| 样本内与样本外 | 参与规则选择的数据与未用于选择的数据有区别，反复看过后需记录污染 | [M10-U04](modules/module-10.md#u04-p02) |
| 包含与方向处理 | 缠论中在声明方向与规则后处理高低区间，合并并非任意删K线 | [M11-U01](modules/module-11.md#u01-p01) |
| 分型与确认 | 中间元素的位置早于右侧元素完成后的确认时间 | [M11-U02](modules/module-11.md#u02-p01) |
| 笔与线段 | 在不同条件下定义的结构，线段不能简化为任意三笔连接 | [M11-U03](modules/module-11.md#u03-p01) |
| 特征序列 | 按指定方向抽取用于线段分析的元素，包含与缺口需要按声明口径处理 | [M11-U04](modules/module-11.md#u04-p01) |
| 中枢 | 在给定级别与次级别走势类型前提下定义的重叠区域，不等于任意三根K线重叠 | [M12-U01](modules/module-12.md#u01-p01) |
| 周期与级别 | 图表时间窗口与走势递归关系并非一一对应 | [M12-U02](modules/module-12.md#u02-p01) |
| 背驰与MACD代理 | 缠论的比较对象和条件需先声明，指标表现只是特定辅助观察 | [M12-U03](modules/module-12.md#u03-p01) |
| 三类买卖点 | 在相应结构、级别和确认条件下定义的分类，需同时说明实时可知性 | [M12-U03](modules/module-12.md#u03-p02) |
| 区间套 | 在多级别关系中缩小观察范围的分析方式，结果仍受确认与解释前提约束 | [M12-U04](modules/module-12.md#u04-p01) |
| 亏损、盈利、时间、逻辑退出 | 四种不同触发原因，应分别写出可执行动作 | [M13-U01](modules/module-13.md#u01-p01) |
| 计划损失与实际损失 | 跳空、未成交和费用变化可能使实际结果偏离估算 | [M13-U02](modules/module-13.md#u02-p01) |
| 规则版本与临时改动 | 事先固定、留痕的研究修改，与为解释刚发生的结果而随意改规则不同 | [M13-U04](modules/module-13.md#u04-p01) |
| 回放与前向模拟 | 已有历史逐步揭示，与今后新行情下事前记录的练习不同 | [M14-U02](modules/module-14.md#u02-p01) |
| 过程与结果 | 决策和执行按当时证据评价；方法有效性结合总体样本另判 | [M14-U04](modules/module-14.md#u04-p01) |

交易过程需要的完整表格见[交易练习](trading-practice.md#templates)。
