# CB02 · 动力学

先能在合格构件上画中枢，再学比较。以下例子都是自编教学数据。结构可以用于提出待检验的计划，不代表收益或转折已被证明。

## 走势完成与同级分解

来源：第二章第1、2节（PDF 13–19）。「走势终要完成」在书里是理论命题。课堂做法是：在固定口径下，区分已有完成证据、尚延伸和资料截断三种状态。识别出中枢，以及确认该级别的整个走势类型完成，是两件事。已经形成的趋势仍可继续增添同向中枢。不能把「终要完成」理解成能够报出期限或亏损必会回本。

按同一观察级别把连续走势拆成 A、B、C，写出各段的边界、成员、性质及证据。把 A 与 B 暂合在一起或先把 B 与 C 合看，是讨论连接的结合性；它不允许把时间顺序换成 B、A、C。不同分解可以有不同用途：粗分用于固定操作级别，细分用于观察内部，不能以粗分的末端时点代替细分的证据。若改变分解口径会改变行动，保留两种读法及各自失效条件，不能事后只留赚钱那种。

例：A 是已完成下跌，B 是已完成盘整，C 向下但尚无封口证据。可写 A+B 均可定位、C 待确认；不可把全图宣布为「三个完成类型」。假设下一帧出现与 C 原判定不符的返回，追加分解记录，不覆盖旧帧。对照 [C12-F例](../chan-trace.md)，写出哪三段是见证、哪几段是成员。

## 均线力度、趋势背驰与盘整背驰

来源：第二章第3、4节（PDF 19–22）。均线口径下，从上次相交结束算到下次相交开始，累计两条均线间的面积，得到完整区间的趋势力度；若尚未再次相交，可以算到观察截止的累计面积除以已过时间，得到当时的平均力度。用等间隔、单位步长的离散示范：已闭合段三格间距 2、2、2，面积6；当前段只走了两格，间距 3、1，目前为4，平均为2，最终总面积仍未知。即使已完成段的总面积较小，也不表示平均力度一定较小。统一采样和积分口径再比较。

第二种是 MACD 辅助比较。先固定级别、方向、入离中枢关系、数据基准、参数和柱值累计方法。典型趋势例按 M12 比较同向 A、C：已有合格下跌背景，A 的负柱绝对面积8，C 当前面积5并创新低，最多得到辅助减弱候选。尾部未完，新增柱可使面积增为9。围绕一个中枢做的盘整背驰，属于另一种结构语境，不用「第一次出现指标背离」充当完整趋势。指标减弱、结构完成、转折有多大、下一步是否交易须分别回答。参见作者[第24课](https://blog.sina.com.cn/s/blog_486e105c0100087y.html)、[第27课](https://blog.sina.com.cn/s/blog_486e105c010008h4.html)及 [M12-U03](../modules/module-12.md#u03-p01)。

练习：若 A 为30分钟图同一取样方法下的已完成段，C 却取5分钟图最新三根柱，为什么即使面积更小也不能直接比较？怎样重取证？

## 中枢震荡和中阴

来源：第二章第5、6节（PDF 22–26）。中枢震荡是围绕所选中枢识别来回波动。把每条次级走势、与核心的相交关系和完成状态列出来；触及核心与离开后完成不回核心是不同事件。一次上冲不等于第三类点，须检查首次合格返回及其全幅。再平衡或短差的设想还须分别给出量、成交限制与成本。

中阴阶段说的是前一走势类型已有结束依据、接续方向还未明朗的过渡。不能把任何窄幅横盘都叫中阴，也不能用这个名称反证上一类型已完。例：核心 [10,12]；已经有前段完成材料，首次向上回试仍触到 11，尚不能记为向上脱离成功。保留 A：继续围绕旧核心；B：待新的合格离开和回试后确认脱离；C：出现外围重叠或更大结构条件，重新核资格。若三个条件都未满足，继续观察。注意这不是预测何日结束。

附件以布林通道收口辅助提醒中阴可能结束。可用自编序列练习：上轨、下轨分别从 16、8 收到 14、10，宽度由8减到4，只说明通道变窄。即使采用更大取样周期，这也不证明低层已结束，更不能沿用书中接近100%的有效率说法；仍须核本层完成、离开和返回。

## 转折的力度与级别

来源：第二章第7节（PDF 26–30）。作者在[第43课](https://blog.sina.com.cn/s/blog_486e105c010009mm.html)复述第29课的三种结果：趋势最后一个中枢的级别扩展、比该趋势级别更大的盘整、该级别或更高的反趋势。这里「更大」的比较对象须说清，不能把第二种改成同级盘整，也不能把第三种限于同级。课程把它们作为符合定义后待检验的分类，学生要给每条路径的构件和证据。反弹幅度不能替代级别。小级别转折只有在较大背景及后续证据支持时，才可能改变大级别判断。

例：较低层向上反弹突破前一个小高点，较大层仍只有一段未完成的上行。合法旧记录写「小层反向，较大层类型未知」，给出较大层需要哪几段、哪个核心、何时可知。若开盘跳空又越过旧边界，先排查公司行动和输入口径；不能把一个区间没有报价当成既有结构被证实。

## 走势结构的两重表里关系

来源：第二章第8节（PDF 30–32）。书用笔的方向和状态配对，方向取 +1 或 −1，状态区分延伸与分型构造。比如较大观察周期仍向上延伸，较小周期开始出现向下变化，是预警而非较大结构完成；较大周期也形成合格反向证据时才更新较大层。附一份并列记录：时点、周期、已完成输入、各层状态、证据何时可知、所缺条件。

示范：10:00 大周期向上笔仍在延伸，小周期出现顶构造。10:05 小周期确认反向，较大周期右侧 K 线仍未收。两次都不能将较大周期直接改为「已完成向下笔」。练习：用不同观察间隔重写记录，解释何时能改哪一列，并指出单位时间周期与递归级别分属两套标记。
