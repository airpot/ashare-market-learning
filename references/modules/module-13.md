# 模块十三：退出、仓位管理与行为约束

第十模块已经把信号放进完整策略；第十二模块进一步区分了结构与确认。本模块解决持仓之后怎么办。青禾制造、小林、账户金额、价格、费用、观察时刻和暂停阈值全部是虚构教学假设，适用于本课无杠杆现金多头模拟，不是交易所规则、个人建议或已验证策略。现实费用、产品权限及可用数量须单独核实。

## 第一单元：四种退出理由

<a id="u01-p01"></a>
### 第一讲：止损是撤退条件，不是最大亏损保证

止损退出，是当价格或结构违反预先的容忍边界时，执行减仓或离场计划。它的作用是限制继续承担的风险，不是保证卖在某个价格。先区分“什么信息触发行动”和“用什么委托表达行动”：触发价不等于成交价；限价限制接受价格，却可能没有成交。美国监管投教机构的[止损订单说明，2026-08-18 更新](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15)可帮助理解这一通用区别，不能据此断言 A 股券商具备同样订单功能。

虚构策略 H1.0 规定：小林按 10 元买入青禾制造 600 股，模拟总资金 20,000 元；最近已确认结构失效位为 9.5 元。初始价差风险为 600×0.5=300 元，另留总费用与执行偏差预算 40 元，计划风险 340 元，小于本课自定的单次预算 400 元。这个预算是推算条件，不是账户保险。

若下一个可执行窗口只有 9.2 元的成交机会，全部成交且教学总费用 40 元，则损失为 600×(10−9.2)+40=520 元，超过预算。不能在记录里改写成“按 9.5 止损，所以只亏 340”。也不能因为已超预算，就把失效位往下搬来维持原判断。

盘中触发和收盘确认是两种不同策略。若规则等收盘，盘中刺破后收回可能不触发；若盘中触发，不能看到收回后撤销“曾经触发”的历史。需要分别评价延迟和误触发的代价。

自然检查：小林正确写了止损价，为什么仍可能亏得比预计多？哪两个字段必须分开记录？

<a id="u01-p02"></a>
### 第二讲：止盈、时间退出和理由失效

止盈，是达到预定兑现条件时退出；时间退出，是超过允许等待期仍未出现预期表现时退出；理由失效，是支撑交易的事实被新证据推翻。三者都须在入场前规定观察窗口与行动优先级。不能只写“走势不好就卖”，那会让任何结果都能被事后解释。

虚构 H1.0 选择固定兑现而非移动止盈：可卖条件满足后，若价格达到 11 元按计划检查全部退出；若三个完整持仓交易日内的最高收盘价仍低于 10.5，则在下一可执行窗口退出。这里只演示两个不同触发器，三个交易日不是最佳持有期限。如果入场理由是“合成公告显示产能已获批”，后来可用的新资料明确否定这一前提，理由失效具有更高优先级，不必等价格止损。

用上讲 600 股、10 元入场，若全部按 11 元成交，教学总费用 40 元，净利润为 560 元。以初始计划风险 R0=340 元表示，约为 1.65R，不能把毛价差的“赚一元、冒五角风险”直接写成成本后赚 2R。R 是统一比较单位，分母定义须事前固定，不能赚了后换小分母。

反例是上涨后临时把目标改成 12，跌回后再改称长期投资；这已经改变策略。若原本采用移动退出，例如只按已收盘高点上移撤退边界，就另设版本，并接受可能回吐部分浮盈，不能要求同时卖在最高点。

自然检查：时间期限到了，青禾制造还略有浮盈，小林为什么仍可能需要退出？若理由失效但价格没跌，哪个条件先起作用？

## 第二单元：加减仓与执行困难

<a id="u02-p01"></a>
### 第一讲：加仓后重算总风险，不只盯平均成本

加仓增加持有数量，减仓降低数量；平均成本只是历史资金投入的平均，不代表从现在继续持有的风险。用第四、六模块学过的数量、价格和暴露，把旧仓与新仓合并检查，既看账户承受能力，也看同类持仓的集中程度。不能把浮盈一概当成可以随便亏掉的钱。

虚构情境：旧仓 600 股，现价 10.8，拟新增 200 股，拟执行边界 10.2。从当前价到该边界，每股可能回撤 0.6，合计 800×0.6=480 元，再留教学费用与偏差预算 60 元，为 540 元，超过本课 400 元剩余风险预算。旧仓买在 10 元，并不能抹掉这段权益回撤。

一种供比较的方案是先按可成交条件减掉旧仓 300 股，再考虑加 200 股。此后总持有 500 股，按同样当前价与边界估算 500×0.6+60=360 元。但“先减再加”增加操作与费用，未必值得；还要核实减仓是否真的成交、最新现金是否可用，以及新加仓是否有独立合格信号。最简单的合规决定也可以是维持旧仓、不加。

向下补仓以摊低成本，只有在预先验证的规则允许且组合风险仍受控时才进入讨论；本课 H1.0 不允许亏损加仓。单看“买便宜了”没有说明失效概率、剩余现金或集中暴露。与青禾制造同产业的另一只持仓也可能同时受冲击，不能当作完全独立风险。

自然检查：平均成本下降，是否必然意味着账户更安全？如果计划减掉的 300 股只成交 100 股，原来的加仓计算还能直接用吗？

<a id="u02-p02"></a>
### 第二讲：跳空、未成交与持仓可卖数量

跳空是相邻观察区间之间价格不连续的情况；未成交是已作出交易意图却没有取得成交结果。止损计划要预先回答：价格跨过触发位、出现排队或停牌、只能部分成交时怎么办。不能把没有成交写成没有风险，也不能连续重复提交而不查原订单状态。

截至 2026-10-20 核对的[上交所《交易规则（2026 年修订）》发布通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)写明 2026-07-06 施行；其[正文第 3.1.4—3.1.5 条](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/10816492/files/58bd5ce4dfc94b57a5391f60eb2719ab.docx)区分交收前禁止卖出与回转交易例外。此处以沪市主板普通 A 股为适用示例，不能假设当日新买数量可立即卖回，也不能外推到列明可回转的基金等品种。

同一通知有[暂缓实施条文附件](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/10816492/files/7476908baade49b8b14881439d2f89b6.docx)，包含部分大宗交易安排；不能把修订正文所有时段都视为已开放。本课不依赖这些延后安排，也未逐项检索其后所有启用通知。深市、北交所和券商条件单功能不在本段规则核验范围。

虚构例：小林此前已有可卖 600 股，打算退出，却仅成交 200 股；余 400 股仍承担风险。另一个情境是今天新买 200 股，当天触发风险警报，应记录受限数量与后续可行动方案，不能在模拟账上直接“当天平仓”。若跳空到 9.2 而原卖出限价 9.5 没有成交，先查单号与回报，再按预先规则决定撤改；停牌期间只能保留风险记录与复牌计划。

自然检查：券商界面显示“已触发”，为什么还不够证明退出？已有持仓、可卖持仓、委托未成交持仓应各填什么？

## 第三单元：心理控制与暂停机制

<a id="u03-p01"></a>
### 第一讲：把情绪改写成可观察的动作

心理控制不是要求没有恐惧，而是让恐惧、兴奋和懊悔不能直接变成违规订单。可观察的偏差包括：看到别人盈利便追单，亏后加码求回本，浮亏后临时扩大止损，已有数据不足却只找支持自己的说法。给情绪命名有助于停下来，但真正需要约束的是行为。

小林错过青禾制造 10 元的有效观察，后来涨到 10.8。他写下“怕再错过，想立即加 800 股”。本课示范控制是先离开下单界面，在纸上回答信号是否仍有效、价格是否超出上限、风险预算够不够；三项中任一不满足，就记录一次主动放弃。这个步骤不保证心情立刻恢复，却让动作仍可核查。

亏损后的另一种情境：本来限额是 400 元，第一笔亏 340 元后，小林想把下一笔提高到 800 元。把“我要回本”改写成“拟违反单次限额”，问题就从愿望变成可拒绝的行为。相反，按规则退出后市场再涨，并不自动证明之前错误；只应检查当时条件与执行质量。

理解核对可以很日常：请说出一个“我现在很焦虑”之后能做的具体动作，不要只说“保持理性”。若把暂停理解成放任原仓不管，又会出现什么风险？暂停新增与管理已有风险必须分开。

<a id="u03-p02"></a>
### 第二讲：暂停要有触发、责任与恢复条件

暂停机制是预先写好的停止新增风险条件，用来阻断执行失控或研究假设暂不可用的阶段。触发可以来自纪律偏差、数据异常、持续超预算或生活条件改变；不是必须亏钱才暂停。恢复也不应只凭“感觉好了”或刚好赚了一笔。

虚构政策：同一观察周内出现两次未核对风险就提交的模拟订单，暂停下一次新增；行情资料缺失、无法核对成交回报时立即暂停新增。已有仓位仍按风险计划处理，若无法确认状态，先解决对账。两次只是课程演示阈值，没有被验证为最佳心理控制参数。

小林星期二违规追单却盈利，星期四又越过预算亏损。触发暂停的证据是两次行为记录，不是周净利润。恢复流程为找出触发场景、修正操作步骤、在新的未见案例中独立演示风险核对与撤改顺序，再恢复原先规模的模拟；先不提高限额。

对持续亏损要分辨：规则理解错误需补课；执行偏差需操作控制；规则按要求执行却连续亏损，须做策略及市场状态复核，不能只责备意志力。反过来，暂停期间观察到一个大涨机会，也不构成取消暂停的证据。

自然检查：一笔违规盈利该不该计入暂停触发？若只是行情断档，修复后还要补哪项证据才恢复模拟？

## 第四单元：版本化策略与风险复核

<a id="u04-p01"></a>
### 第一讲：先冻结版本，才能知道测的是什么

策略版本是某组完整规则的身份标记。必须同时包括候选范围、观察截止、入场、退出、规模、撤改、再次进入和暂停条件。否则小林今天用收盘信号、明天用盘中信号，把结果混在一起，无法判断究竟哪种方法发生了什么。

H1.0 使用固定目标与三个持仓日时间检查；小林后来想改成跟踪已收盘高点移动退出，应写 H1.1，注明变更理由、开始使用的日期和待观察问题。旧结果保留 H1.0，不把亏损样本改写成“按新规则本来会盈利”。只改错别字可以记录文档修订；改变任何实际决策条件，就应保留新的策略身份。

原作者的[回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)说明，在有限资料上反复筛选大量变体会产生看似优秀的结果。此处的教学含义是公开尝试次数和选择过程，再用事前冻结的新观察检验；不是要求初学者写代码或宣称某种留出方法一定能证明有效。

具体做法可以只用纸卡：左栏原规则，中栏拟改内容，右栏为什么改、要看什么反例。若新版本同时改入场、持有期和止损，结果改善也很难归因；尽量让研究问题清楚，安全修正则立即生效并中止旧实验，不为保持样本而延续已知错误。

自然检查：把止损观察从盘中改成收盘，为什么需要新版本？若后来涨得很好，能否把旧版亏损从记录里删除？

<a id="u04-p02"></a>
### 第二讲：完整决策单与定期风险复核

复核是把已知事实、尚未发生的行动、实际执行和研究判断放回同一张时间表。先核事实再评得失，尤其核对多笔持仓是否共享风险来源、费用是否漏记、受限数量是否被当成可卖。单笔看起来小，不等于账户合计也小。

| 字段 | 小林的虚构已填写记录 |
| --- | --- |
| 版本与资料 | H1.0；合成包 R13；D1 收盘确认，下一可执行窗口才考虑入场 |
| 入场与风险 | D2 实际买入 600 股，均价 10；失效位 9.5；R0=340，预算 400 |
| 退出规则 | 止损优先；事实理由失效立即重查；目标 11；三个完整持仓日后作时间检查 |
| 执行限制 | 数量按可卖核对；触发不等于成交；未成交逐单登记 |
| 后续观察 | D4 开盘跳至 9.2，原限价未成交；查回报后按预设撤改方案处理 |
| 实际结果 | 假定最后全在 9.2 成交，总教学费用 40；净亏 520，约 −1.53R |
| 过程结论 | 入场和规模合规；须检查退出委托是否依计划；跳空超预算单列 |
| 下一步 | 原单、撤改、成交时间均保留；复核跳空压力情景，未核清前不提高规模 |

这个例子没有把所有亏损都归为操作错，也没有因入场合规就宣布整笔无须改进。若撤改单号或时间缺失，过程结论就是证据不足，不能自评满分。若模拟采用事前保守成交假设，必须标明，不能把它当实际市场回报。

迁移检查：把 D4 改成“只卖掉 200 股，其余未成交”，应先改哪个账户字段，后改哪个结果字段？为什么剩余仓位不能被当作已经实现亏损的现金？
