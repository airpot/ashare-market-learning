# 练习二：行情、K线与蜡烛图

以下为普通交易日的合成价格，无除权除息，单位为元。

| 数据 | 数值 |
| --- | ---: |
| 昨收 | 22.00 |
| 开盘 | 20.00 |
| 最高 | 21.80 |
| 最低 | 19.50 |
| 收盘 | 21.00 |

1. 画出K线，标明实体、上下影线及四价。解释阴阳和日涨跌分别采用什么基准。
2. 仅凭这些数据，能否确定当天先出现最高价还是最低价？给出你的依据。
3. 若将几根分钟K线合成一根更长周期K线，开、高、低、收如何取值？若最后一根尚未结束，你会如何描述它？
4. 一根下影较长、实体较小的线，分别出现在连续下跌后和连续上涨后。你还需观察什么，才能解释其含义？
5. 软件甲显示前复权，乙显示不复权，同一天历史价格不同。你会核查哪些字段？何时可以把图上数值当作当时实际成交价？
6. 某软件显示“主动买入金额”较大。请把可直接观察的统计字段与对交易者意图的判断分别写出。

## 新情境甲：两根蜡烛究竟是什么关系

以下青禾价格另为合成日线，与前六题无关；同一未复权口径，无权益事件。此前三个完整日收盘依次为 16.80、17.40、18.10，作为本题已知的上涨背景，不据此声称所有波段高低点都抬高。

本题沿用课堂定义：孕线要求第二根实体两端严格位于第一根实体内部；内包线要求第二根最高、最低严格位于第一根全幅内部；向下吞没要求第二根阴实体严格跨过第一根阳实体两端。乌云采用课堂版本：上涨背景中，第一根为阳线，第二根高于前收开盘，收在第一根开盘以上、实体中点以下；边界相等不算严格成立。它们都是描述约定，并非有效性或买卖保证。

7. 独立判断此组合满足哪些定义、不满足哪些定义。列出两根实体区间、第一根实体中点，逐项写出数值不等式，不只报名称。分别解释实体关系、全幅关系与此前背景。另作两个互斥分支：只将乙日整根替换为 O=18.90、H=19.15、L=18.25、C=18.40；或替换为 O=18.90、H=19.15、L=18.25、C=18.50。两分支各如何改变分类，哪项严格边界需要核对？最后写一条后续确认条件与一条反证条件，注明判定时间；只用截至乙日收盘的资料，说明仍未知什么、为何不能直接推出交易收益。不要把两个替换分支拼成连续两日。
