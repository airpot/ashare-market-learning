# 练习三：完整规则与验证

本题检验规则能否解释、计算和执行，尚不假设任何策略有收益优势。

## 规则草稿

“上涨趋势里出现放量突破就买，赚了卖，跌破支撑就止损。”

1. 请将其改写成别人可以据同一数据执行和核查的教学规则。标明数据周期、背景、触发、确认、申报、数量、退出和不交易条件。尚缺的数据可以提出需求。

## 时间与执行

S5收盘21.2元后，才可计算一项使用该日完整收盘数据的信号。后续S6开盘22元。本题没有提供可执行的收盘竞价订单。

2. 你会把信号确认、计划申报和假设成交分别记在哪个时点？还需哪些信息才能记录真实成交？

## 结果样本

一组十笔合成交易：四笔各盈利300元，六笔各亏损100元；这些数字尚未扣费用，每笔总费用20元。

3. 总净收益、胜率和每笔平均净结果分别是多少？只报告胜率会遗漏什么？
4. 若这一组是从很多参数与股票组合中挑出的最好结果，你希望看到哪些研究记录及后续验证？
5. 你会选择什么比较基准？比较时还需说明哪些仓位、风险和费用差异？
6. 一根K线最高12、最低8、开10、收11；计划退出观察价分别为9和11.5。没有更细数据时，怎样记录这一根线对退出先后与成交结果的支持范围？
