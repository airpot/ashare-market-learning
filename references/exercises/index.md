# 阶段练习

先讲解、再练习。阶段练习选择你尚未见过的虚构案例，保留原始回答后再给反馈；曾看过的题改记有辅助。你可以要求提示，提示后的表现会单独记录。需要严格先决策、后开放行情的连续迁移时，用[保留回放入口](../holdout-replay.md)，先核对已见资料范围。

| 阶段 | 学习范围 | 学习材料 |
| --- | --- | --- |
| S01 | M01—M05：市场、账户、交易、费用、风险与观察名单 | [练习一](stage-01.md) |
| S02 | M06—M08：行情、K线与蜡烛形态 | [练习二](stage-02.md) |
| S03 | M09—M10：走势、量价、完整规则与验证 | [练习三](stage-03.md) |
| S04 | M11—M12：缠论结构、级别与确认 | [练习四](stage-04.md) |
| S05 | M13—M14：管理、执行、记录与评估 | [练习五](stage-05.md) |
| S06 | M15与所选产品M16—M19、M20：机制、事件、交易与核算 | [多品种阶段练习](product-stage.md) |

练习材料不包含教师答案。你也可先选择带提示的练习，之后再用另一份案例检查独立理解。

S06当前为六条辅助纸面训练，不作为独立未知行情测验。保留每一步原始回答后才进入匹配反馈；可选一条先学，不要求一次做完所有品种。
