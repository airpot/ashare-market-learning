## Source limits

Sina day-bar observations have no adjustment. Dates use Asia/Shanghai (UTC+8). Keep the initial OHLC and volume strings without change.

Prices use CNY/fund-unit. For sz123107, prices use CNY/bond. Volumes use fund-units or bonds.

For comparison only, multiply Tencent volume by 100 for funds and 10 for the convertible. Keep Sina volume without change.

The frozen comparison gives the same OHLC values. After rounding, the maximum difference in comparison volumes is 50 fund units or 5 bonds.

The providers can have the same data source. This is an interface comparison. This comparison does not show, independently of the providers, that its data agrees with exchange data.

The last observation date is 2026-10-19. Sina retrieval timestamp date: 2026-10-20.

The Tencent timestamp is the capture file modification time. From it, you cannot be sure of the retrieval time.

From this atlas, you cannot be sure that its corporate-action, distribution, halt, permission, or settlement calendar is full.

The supplied data contains no NAV, IOPV, FX, or conversion price for the same time. It contains no underlying stock history.

From these charts, do not get this information:

- A premium from market observations
- Total return
- Fills that occurred
- The quality of order execution
- An assessment without previous access.

## Teacher routing after the raw response

For this atlas of recorded source data, the tutor must do the check of the raw response. There is no program gate for atlas file access.

Before you read teacher material, record the raw response in an external learner record. Include its case ID, cutoff, attempt, and aid/exposure status. Exposure status includes price data and other material that the learner saw, with or without answers. The raw response must not be empty.

Before you read teacher material, make sure that these fields in the recorded raw response agree with this step:

- Case ID
- Cutoff
- Attempt.
If the raw response is missing or empty, continue with learner material for this step. Do not read teacher material.

If the case ID, cutoff, or attempt is different, continue with learner material for this step. Do not read teacher material.

After feedback, do not replace or change the raw response.

Only after this check, get `references/assessment/product-atlas/{id}.json` for the case.

Read its five `future_bars`. Use only its matching outcome files for feedback.

Do not load other cases, full histories, or outcomes before the applicable raw responses. The HTML without hints contains no link to subsequent files.

The teacher annotation uses the ten observations immediately before the cutoff. It does not include the cutoff bar.

The mean volume for the last 20 observations also does not include the cutoff bar. These references that do not change do not identify investor motives.

The full frozen source is `assets/chart-data/teacher-products-2026.json`. This file is teacher material and development material.

The file contains source URLs, source response hashes, retrieval metadata, comparison limits, and the 1,888 source bars.

The different paper-practice runtime has a feedback gate that a program operates for its synthetic ETF, LOF, CB, and other track packets.

The gate does not examine real-atlas responses or prevent access to atlas files. It is not a control for atlas access.

After access to price data or other material, practice with previous market data must keep `assisted` status. From subsequent profit, you cannot be sure of decision skill.

## Optional development record (repository only)

This section is for source maintainers. Commands for the build and development evidence are not necessary for the teaching runtime.

The portable atlas contains its learner packets and images. For installed operation, repository tools and a local browser are not necessary.

Source maintainers can use `python -B tools/ashare-market-learning/build_product_atlas.py` from the repository.

The generator reads only frozen local evidence. Before output, it examines metadata and raw response hashes.

Source maintainers can render changed SVG files with `tools/ashare-market-learning/render_chart_pngs.py`.

The build record gives checks and limits in `assessment/product-atlas/build-record.json`.

The development bitmap manifest contains PNG hashes and dimensions. This manifest is not a publication record.
